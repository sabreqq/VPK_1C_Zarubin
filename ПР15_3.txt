        ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.ЦеныНоменклатуры.СрезПоследних(&Период, ВидЦен = &ВидЦен) КАК ЦеныНоменклатурыСрезПоследних
        ПО ВТ_СписокНоменклатуры.Номенклатура = ЦеныНоменклатурыСрезПоследних.Номенклатура
            И ВТ_СписокНоменклатуры.Характеристика = ЦеныНоменклатурыСрезПоследних.Характеристика
        
        // Курс валюты из Заказа
        ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.КурсыВалют.СрезПоследних(&Период, ) КАК КурсДокумента
        ПО ВТ_СписокНоменклатуры.ВалютаДокумента = КурсДокумента.Валюта
        
        // Курс валюты из Регистра Цен (используем ВалютаЦены)
        ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.КурсыВалют.СрезПоследних(&Период, ) КАК КурсЦены
        ПО ЦеныНоменклатурыСрезПоследних.ВалютаЦены = КурсЦены.Валюта
;
